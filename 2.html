📜 Game Rules

Read carefully before starting the game

🎯 Objective

Score as many runs as possible against the AI opponent using hand gestures (1–6). If your number matches the AI’s number, you are OUT.

✋ Hand Gesture Mapping

  • 1 finger → 1 run
  • 2 fingers → 2 runs
  • 3 fingers → 3 runs
  • 4 fingers → 4 runs
  • 5 fingers → 5 runs
  • 6 fingers → 6 runs

🧠 AI Strategy

  • Early Game: Random guesses
  • Mid Game: Learns your frequently used numbers
  • End Game: Aggressive prediction to get you OUT

🏏 Scoring Rules

  • If your number ≠ AI number → Runs = your number
  • If your number = AI number → OUT
  • Each gesture counts as one ball

🏆 Winner Selection

Winner is decided using the following order:

  1. Highest total runs
  2. If runs are same → Higher Strike Rate wins
  3. If still tied → Fewer balls played

Strike Rate = (Runs / Balls) × 100

📊 Leaderboard

A live leaderboard shows all players with their runs, balls played, and ranking in real time.

🎥 Camera & Offline Mode

  • Ensure good lighting for camera mode
  • Keep hand inside camera frame
  • If camera fails, use Offline Mode (buttons 1–6)

👁️ After You Are OUT

After getting OUT, a Face Structure Similarity feature shows which Indian male cricketer you resemble (for entertainment only).

⚠️ Disclaimer

This game is for demonstration and entertainment purposes only. Face similarity is not identity recognition. Data is used only during the fest.
